# PCB Simplifier Web 展示版

此 Repository 僅公開 PCB Simplifier 的 Web 前端展示版本，用於展示 PCB 2D Layout 與 3D 預覽介面。

## 公開內容

- React／Vite 前端原始碼。
- 編譯後的前端展示檔案。
- Web 操作畫面與操作說明。
- 前端套件設定與第三方授權資訊。

## 操作說明

請參閱：[PCB Simplifier 操作說明](docs/操作說明.md)。

## 未公開內容

完整 Python 腳本、FastAPI／PyEDB 後端、桌面版工具、啟動腳本、AEDB／SIwave 專案與模擬資料已移至私人 Repository，不在此公開。

如需完整版本與使用權限，請聯絡 Jeff Hong 洪敬傑洽詢。

## 技術展示

前端使用 React、TypeScript、Vite 與 Three.js，提供 PCB Layout 與幾何預覽介面。
