# PCB Simplifier Toolkit 操作說明

此工具由虎門科技資深技術工程師 Jeff Hong 洪敬傑提供。

PCB Simplifier Toolkit 用於載入 Ansys Electronics Database（EDB）電路板資料、選擇需要保留的網路，預覽精簡前後差異，並輸出新的精簡版 `.aedb`。

## 1．工具畫面

![PCB Simplifier Toolkit Web 操作畫面](../PCB%20Simplifer%20Toolkit%20Web操作畫面.png)

畫面主要分成三個區域：

1. 左側設定區：載入 EDB、選擇保留網路、設定輸出路徑及開始精簡。
2. 中央 Layout 預覽區：顯示原始電路板及精簡後結果。
3. 下方系統日誌：顯示載入、預覽、精簡及錯誤訊息。

選取一個以上的網路後，中央預覽會自動分成左右兩側：

- 左側：完整的原始電路板。
- 右側：只保留所選網路的精簡預覽。

## 2．執行前需求

### 2.1 作業系統

- Windows 10／11，64 位元。

### 2.2 必要軟體

- Python 3.10～3.12，64 位元。
  - 用途：建立專案專用虛擬環境，執行 FastAPI 與 PyEDB。
  - 若電腦只有 Python 3.13／3.14，或完全沒有相容版本，啟動器會透過 Windows WinGet 自動安裝 Python 3.12（使用者範圍、64 位元）。
  - Python 3.12 會與既有 Python 3.14 並存，不會移除、降級或覆蓋其他版本。
  - 若公司政策停用 WinGet，請由 IT 或使用者手動安裝 Python 3.12。
- Ansys Electronics Desktop 2026 R1，或與 PyEDB 0.80.1 相容且合法安裝的 EDB Runtime。
  - 用途：讀取、修改及儲存 `.aedb`。
  - 本工具不包含 Ansys 商業軟體、商業 DLL 或軟體授權。
- 第一次啟動需要網路連線。
  - 用途：下載並安裝 Python 相依套件。

一般使用者不需要安裝 Node.js。Node.js 僅供開發者重新建置 React 前端使用。

### 2.3 Python 套件

工具會在獨立虛擬環境中安裝以下套件，不會污染全域 Python：

- `pyedb`：讀取與修改 Ansys EDB。
- `fastapi`：提供本機 Web API。
- `uvicorn`：執行本機 Web 伺服器。
- `websockets`：將系統日誌即時傳送到操作畫面。
- `pydantic`：驗證前後端交換資料。

實際版本記錄於 `backend/requirements.lock.txt`。

## 3．下載與第一次啟動

1. 建議從 GitHub repository 的 **Releases** 頁面下載 `PCB-Simplifier-vX.Y.Z-win64.zip`；也可以使用 **Code → Download ZIP** 下載 Source ZIP。
2. 如 Release 提供 SHA-256，請先核對檔案校驗碼。
3. 將 ZIP 完整解壓縮到具有寫入權限的資料夾。
4. 請勿直接在 ZIP 壓縮檔內執行程式。
5. 進入 `web_app` 資料夾並雙擊 `start.bat`。
6. 第一次啟動時，工具會在 `backend\.venv` 建立專用 Python 虛擬環境。
7. 等待必要套件安裝完成，瀏覽器將自動開啟 `http://127.0.0.1:8010`。

第一次安裝所需時間會受網路速度影響。後續啟動會沿用既有虛擬環境，不會重複安裝全部套件。

## 4．載入 EDB

1. 在「1．輸入檔案」欄位輸入 EDB 路徑，或按下「瀏覽」。
2. 可以指定：
   - `.aedb` 資料夾。
   - `.aedb` 資料夾內的 `edb.def`。
3. 若指定 `edb.def`，工具會自動轉換成其外層 `.aedb` 資料夾。
4. 按下「載入網路清單」。
5. 等待系統日誌顯示 EDB 載入及預覽完成。

大型電路板可能需要數分鐘。載入期間請勿關閉啟動視窗或重新整理瀏覽器。

## 5．選擇要保留的網路

1. 載入完成後，左側會顯示所有網路名稱。
2. 可在搜尋欄輸入部分名稱過濾網路。
3. 點擊左側網路名稱，將其加入右側「已選取」清單。
4. 點擊已選取的網路，可將其移除。
5. 至少選取一個網路後，中央畫面會自動顯示左右對照：
   - 原始電路板。
   - 精簡後預覽。
6. 每次增加或移除網路後，右側精簡預覽會自動更新。

精簡預覽只代表預計保留的 Layout 內容；實際輸出仍以「開始簡化設計」執行結果為準。

## 6．操作 Layout 預覽

### 6.1 平移與縮放

- 按住滑鼠左鍵拖曳：平移 Layout。
- 滾動滑鼠滾輪：以滑鼠位置為中心縮放。
- 按下右下角「Fit All」：將全部可見圖元重新置中並縮放至畫面範圍。

原始與精簡後兩側預覽可以分別平移、縮放及執行 Fit All。

### 6.2 調整分割畫面

- 拖曳原始板與精簡板中間的分隔線，可調整左右寬度。
- 拖曳 Layout 與系統日誌中間的分隔線，可調整上下高度。

### 6.3 Layers 面板

Layout 右側管理面板提供 `Layers`、`Components` 與 `Nets` 三個分頁。

Layers 分頁提供以下控制：

| 欄位 | 功能 |
|---|---|
| 填滿／框線 | 切換銅箔實心填色或只顯示外框。 |
| 顯示／隱藏 | 顯示或隱藏整個圖層。 |
| 銅箔平面 | 顯示或隱藏 Polygon／Plane。 |
| 導線 | 顯示或隱藏 Trace／Path。 |
| 焊盤 | 顯示或隱藏 Pad。 |
| 過孔 | 顯示或隱藏 Via。 |
| 元件 | 顯示或隱藏 Component。 |

點擊欄位標題圖示，可以一次切換所有圖層的相同項目。管理面板也可以使用側邊箭頭收合或展開。

### 6.4 Components 與 Nets

- `Components`：搜尋、全選、全不選或個別顯示元件。
- `Nets`：搜尋、全選、全不選或個別顯示網路。

這些設定只影響畫面顯示，不會直接修改原始 EDB。

## 7．設定輸出路徑

1. 在「3．儲存設定」欄位輸入輸出路徑，或按下「瀏覽」。
2. 輸出名稱必須使用 `.aedb`。
3. 建議使用新的檔名，例如：

```text
Example_Simplified.aedb
```

請勿將輸出路徑設定成原始 `.aedb`，避免覆蓋或破壞來源資料。執行前建議另外備份重要專案。

## 8．開始簡化設計

1. 確認已選擇所有要保留的網路。
2. 確認輸出路徑正確。
3. 按下「開始簡化設計」。
4. 工具會依序處理：
   - 移除不屬於保留網路的導線與銅箔。
   - 移除不屬於保留網路的過孔。
   - 過濾不再需要的元件。
   - 將結果另存成新的 `.aedb`。
5. 等待系統日誌顯示「簡化流程完成」。
6. 使用 AEDT／SIwave 開啟輸出 `.aedb`，確認疊構、網路、元件及幾何內容正確。

簡化期間請勿關閉啟動視窗、瀏覽器或 Ansys 相關背景程序。

## 9．系統日誌

系統日誌會顯示：

- EDB 載入狀態。
- 圖層、圖元、過孔及元件提取數量。
- 預覽更新狀態。
- 精簡與儲存進度。
- 錯誤原因。

新訊息抵達時，畫面會自動捲動到最新內容。若使用者正在向上閱讀舊訊息，系統不會強制跳回最下方。

按下「清除訊息」可清空目前畫面上的日誌；此操作不會中止正在執行的工作。

## 10．結束工具

1. 完成操作後，先確認輸出檔案已寫入完成。
2. 回到啟動工具的 PowerShell 視窗。
3. 按下 `Ctrl+C`，或直接關閉該視窗。
4. 後端停止後，本機 8010 埠會自動釋放。

## 11．常見問題

### 11.1 無法自動安裝 Python 3.12

工具會先尋找 Python 3.10～3.12；若只找到 Python 3.14，會透過 WinGet 自動安裝 3.12。若 WinGet 不存在，或安裝遭公司權限、Proxy 或安全政策阻擋，請手動安裝 Python 3.12（64 位元），並確認：

```powershell
python --version
```

可以正常顯示版本。

### 11.2 8010 埠已被占用

通常是上一次啟動的後端尚未結束。請先關閉舊的 PCB Simplifier PowerShell 視窗，再重新執行 `start.bat`。

### 11.3 `edb.def` 無法載入

請確認 `edb.def` 位於完整的 `.aedb` 資料夾內。不可只複製單獨的 `edb.def`；其餘 EDB 資料檔也必須存在。

### 11.4 日誌只出現在 PowerShell

請確認 `websockets` 已成功安裝，並重新整理瀏覽器。若仍無法顯示，可刪除 `backend\.venv` 後重新執行 `start.bat`，讓工具重建虛擬環境。

### 11.5 Layout 沒有完整顯示

1. 按下「Fit All」。
2. 確認 Layers 的「顯示／隱藏」已勾選。
3. 確認 Components／Nets 分頁沒有將需要的項目隱藏。
4. 查看系統日誌是否有圖元提取錯誤。

### 11.6 輸出的 `.aedb` 無法開啟

- 確認輸出使用 `.aedb` 副檔名。
- 確認簡化過程沒有被中斷。
- 確認 AEDT／EDB Runtime 版本相容。
- 使用原始 EDB 備份重新執行。
- 保留系統日誌內容，以便後續診斷。

## 12．資料安全提醒

- 工具僅監聽 `127.0.0.1:8010`。
- PCB 資料在使用者電腦本機處理。
- 工具不會主動將 `.aedb` 上傳到外部伺服器。
- 請勿將客戶機密 `.aedb`、輸出結果或系統日誌提交到公開 GitHub repository。
